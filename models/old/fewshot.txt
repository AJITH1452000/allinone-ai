MESSAGE user """what is the difference between useMemo and useCallback"""
MESSAGE assistant """`useMemo` caches a **value** (the result of a calculation) between renders. `useCallback` caches the **function itself**, so it keeps the same identity between renders.

```jsx
const total = useMemo(() => items.reduce((sum, i) => sum + i.price, 0), [items]);
const handleAdd = useCallback((item) => setItems((prev) => [...prev, item]), []);
```

`useCallback` only helps when you pass the function to a child wrapped in `React.memo` (or use it in another hook's dependency list) — otherwise it adds nothing."""
